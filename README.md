# Сайт консалтинговой фирмы по стратегическим закупкам

Корпоративный сайт со встроенной CMS и системой управления документами (DMS). Работает целиком на
Cloudflare: один Worker и хранилище Durable Object (SQLite). Отдельного сервера, базы данных
или платных подписок не нужно.

- **Сайт:** https://procurement-site.imakanovr.workers.dev (временный адрес до подключения домена)
- **Админка:** https://procurement-site.imakanovr.workers.dev/admin
- **Инструкция для редактора:** [docs/EDITING_GUIDE.md](docs/EDITING_GUIDE.md)

## Что умеет

**Языки:** русский (`/`), казахский (`/kk`), английский (`/en`). Перевод хранится как наложение на русский контент (пустое поле = русский текст), в админке — вкладки «Рус | Қаз | Eng».

| Требование | Как реализовано |
|---|---|
| Главная, О нас, Услуги, Аналитика, Контакты | Серверный рендер HTML, тексты и картинки берутся из CMS |
| Баннер на главной зависит от местоположения | «Баннеры по регионам»: страна или континент посетителя (`request.cf`) → свой фон и заголовок. Проверка: `/?geo=KZ`, `/?geo=DE`, `/?geo=AE` |
| 3 страницы специализаций, место для логотипов клиентов | Коллекция «Специализации» (`/services/<адрес>`), логотипы — коллекция «Логотипы клиентов» |
| Страница контактов с формой | Поля формы настраиваются в CMS; заявки хранятся в админке, есть выгрузка в CSV, уведомления на e-mail (Resend) и в Telegram, защита от спама |
| Примеры проектов (пока скрыты) | Коллекция «Примеры проектов»: заголовок, слоган, резюме, результат, изображение. Раздел включается галочкой в настройках |
| DMS: загрузка, скачивание, метаданные, автонумерация | «Документы (DMS)»: тип, направление, дата, название, владелец, клиент/проект, доступ, теги; номер `POL-STR-2026-001` и имя файла по шаблонам; версии; публичные документы скачиваются со страницы «Аналитика» |
| GA4 и уведомление о cookie | GA4 загружается только после согласия посетителя; Measurement ID и тексты баннера — в настройках |
| CMS с редактированием JSON Schema | Формы админки строятся по JSON Schema (`src/schemas.js`), схемы можно править в админке. Разметка schema.org (JSON-LD) генерируется автоматически и дополняется вручную на каждой странице |
| Всё редактируется через CMS | Тексты, кнопки, меню, подвал, изображения, поля формы, подписи интерфейса, SEO-теги, переводы |
| SEO и скорость | Статический HTML без внешних шрифтов и фреймворков, CSS встроен в страницу, адаптивные WebP-изображения; canonical, sitemap.xml, robots.txt, Open Graph, JSON-LD |

**Lighthouse (живой сайт, 27.10.2026):** производительность, доступность и best practices — 100/100
на мобильных и десктопе (LCP 0,2–1,0 с, CLS 0). SEO — 100 при включённой индексации; до запуска
индексация намеренно выключена (noindex), поэтому сейчас SEO показывает ~66.

## Устройство

```
src/
  index.js            Worker: маршруты сайта, API админки, медиа, файлы, форма заявок, sitemap
  store.js            Durable Object «Store» (SQLite): контент, медиа, документы, заявки, пользователи
  schemas.js          JSON Schema всех типов контента (по ним строятся формы админки)
  seed.js             стартовый контент (тексты-заглушки)
  content-types.js    списки типов контента
  render/             шаблоны страниц (layout.js — каркас и SEO, pages.js — страницы, art.js — иконки)
  lib/                markdown, хеширование паролей, нумерация DMS, утилиты
  client/             браузерная часть: site.css/site.js (сайт), admin.js/admin.css (админка)
  static-art.js       заглушки баннеров и логотипов (SVG, собираются в статику)
build.mjs             сборка: dist/worker.js + статика dist/assets
wrangler.toml         конфигурация Cloudflare Worker
test/                 юнит-тесты, e2e в браузере (Playwright), скриншоты
docs/                 инструкция для редактора и скриншоты
```

- **Хранилище.** Один Durable Object с SQLite (бесплатный тариф: 5 ГБ). Файлы (изображения,
  документы) хранятся в нём же кусками по 1 МБ. Лимиты: изображение до 8 МБ, документ до 25 МБ.
- **Кеш.** Снимок контента кешируется в памяти Worker на 10 секунд, поэтому правки появляются на сайте
  через 10–20 секунд. Медиафайлы кешируются навсегда: адрес у каждой загрузки уникальный.
- **Изображения.** Админка сама уменьшает фото в браузере и сохраняет их в WebP размеров 480/960/1600/2400 px.
  Сайт отдаёт `srcset`, и браузер выбирает нужный размер.
- **Безопасность.** Пароли хранятся как PBKDF2-SHA256 (100 000 итераций), сессия — в HttpOnly-cookie.
  Изменяющие запросы защищены от CSRF, на входе и форме заявок стоит ограничение частоты.
  Действует CSP с nonce. Роли: администратор и редактор.

## Установка копии для нового клиента

```bash
CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... node scripts/new-client.mjs имя-клиента [--region eeur]
```

Скрипт собирает проект, делает отдельный конфиг в `clients/<имя>/`, задаёт `SETUP_TOKEN` и выкатывает Worker на аккаунт клиента.
Токену нужно право «Workers Scripts: Edit». Затем клиент открывает `/admin` и создаёт администратора по коду.
Скрипт написан, но на реальном аккаунте не запускался: первый запуск проверьте на тестовом аккаунте.

## Разработка

```bash
npm install
cp .dev.vars.example .dev.vars   # SETUP_TOKEN для локального создания администратора
npm run dev                      # http://127.0.0.1:8787, админка — /admin
npm test                         # юнит-тесты
node test/e2e.mjs http://127.0.0.1:8787 admin@example.com <пароль>   # e2e в Chromium
```

`wrangler dev` пересобирает проект при изменениях в `src/`. Локальная база лежит в `.wrangler/state`.

## Развёртывание

Рекомендуемый вариант: автодеплой из GitHub через **Cloudflare Workers Builds**. Push в `main` сразу
выкатывает сайт.

1. Cloudflare → Workers & Pages → `procurement-site` → Settings → Build → **Connect** → репозиторий.
2. Build command — пусто (Wrangler сам запускает `node build.mjs`), Deploy command — `npx wrangler deploy`.

Вручную: `npx wrangler login && npm run deploy`.

### Секреты (Settings → Variables and Secrets)

| Имя | Зачем |
|---|---|
| `SETUP_TOKEN` | код для создания первого администратора на `/admin` (уже задан) |
| `RESEND_API_KEY` | письма о новых заявках через resend.com (адрес получателя — в настройках сайта) |
| `TELEGRAM_BOT_TOKEN` | уведомления о заявках в Telegram (chat id — в настройках сайта) |
| `TURNSTILE_SECRET` | защита формы Cloudflare Turnstile (site key — в настройках сайта) |
| `IP_SALT` | соль для хеширования IP в заявках |

### Свой домен

Workers & Pages → `procurement-site` → Settings → Domains & Routes → **Add custom domain**
(домен должен быть подключён к Cloudflare). Затем в админке, в «Настройках сайта», укажите
«Основной адрес сайта» (`https://ваш-домен`) и включите «Разрешить индексацию поисковиками».

## Резервные копии

Админка → «Схемы и резервная копия» → **Скачать резервную копию контента (JSON)**: тексты, записи,
метаданные документов и заявки. Сами файлы в копию не входят, оригиналы документов храните у себя.
