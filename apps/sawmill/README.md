# Распил — учёт лесопилки

Одностраничное приложение (без сборки): `index.html` + `demo.js` + фото в `img/`.
Опубликовано как Artifact на claude.ai: https://claude.ai/artifact/A4yPT7M2bUsssjs5udLTTy

## Что ведёт
- **Приёмка кругляка** — побревенный замер (диаметр, длина, штук), объём ≈ ГОСТ 2708-75
  (градация 2 см, сбег 0,7 см/м, ±3 %), сверка с накладной и переплата при расхождении.
- **Распиловка** — смены: кругляк, выпуск по позициям (штуки → м³ по сечению), горбыль, опил,
  выход %, «не учтено» (баланс древесины), выход по пилам и бригадам.
- **Сушка** — камеры, влажность при загрузке / сейчас / цель, прогноз выгрузки.
- **Склад** — остатки считаются из смен и отгрузок; отходы как товар.
- **Продажи** — отгрузки, оплаты, сроки, просроченные долги.
- **Расходы** — ГСМ, пилы и заточка, энергия, ремонт, аренда, оклады, налоги.
- **Финансы** — выручка → сырьё → расходы → зарплата → прибыль, себестоимость 1 м³, маржа по позициям.
- **Зарплата** — сдельная: выпуск смены × расценка каждого члена бригады.
- **Почему Распил** — боли отрасли и как приложение их закрывает (для продаж).

## Хранение
- В Artifact — общая база (`db`): коллекции `products, people, receipts, shifts, sales, expenses, drying`
  и документ `meta/settings`. Автор каждой записи (`createdBy`) показывается в форме.
- Вне claude.ai (или без доступа к базе) — демо-режим в `localStorage` с примером из `demo.js`.
- Примерные записи помечены `demo: true`; удаляются кнопкой в «Справочниках».
